#  Estudio Técnico de Rediseño Institucional - Municipio de Quibdó

Dashboard interactivo para visualizar el análisis y propuesta de rediseño institucional del Municipio de Quibdó, Chocó.

##  Características del Dashboard

- **Análisis Financiero**: Indicadores de sostenibilidad fiscal según Ley 617/2000
- **Estructura Organizacional**: Comparativo actual vs propuesta
- **Brechas Críticas**: Visualización de áreas de mejora
- **Métricas Clave**: KPIs del rediseño institucional

##  Instalación y Uso

### Prerrequisitos
`ash
pip install streamlit pandas plotly
`

### Ejecutar el Dashboard
`ash
streamlit run dashboard_quibdo.py
`
